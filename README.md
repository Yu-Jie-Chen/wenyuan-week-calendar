# 文源教育教学课表

飞书应用模式插件。使用现有课程明细，按北京时间显示周一到周日 08:00—22:00 的课程。

## 配置

1. 在飞书应用页面添加「文源教育教学课表」。
2. 选择已有多维表格和「教学｜课程明细」。
3. 核对课程名称、学生姓名、上课开始、下课时间、授课教师、学科、课程状态、本次课时、关联订单的字段映射。
4. 点击「保存并使用课表」。

## 使用

- 用左右箭头切换周，「本周」回到当前周。
- 按学生、老师、学科或课程状态筛选。
- 白色界面搭配文源教育正式 Logo；通过「配色」菜单按学生、科目或老师区分课程色条，对照下方图例查看分类。
- 点击课程查看学生、时间、老师、状态、课时及关联订单。
- 同时段的课程并排显示；超出 08:00—22:00 的部分不显示。
- 空白周表示该周没有符合筛选条件的课程。

课程由现有数据表管理。组件本身不写入课程、不扣课，也不执行业务自动化。使用者需要拥有数据源的访问权限。

## 开发与托管

需要 Node.js 18 或以上。运行 `npm ci`，然后运行 `npm run build`。构建产物为 `docs`，已在 package.json 的 output 字段声明。运行 `npm run dev` 可本地调试，访问 `http://127.0.0.1:5188/?preview=1` 可查看虚拟课程预览。

预览仅使用明确标注的虚拟示例；仓库不含学生、老师或课程明细数据，也不含访问密钥。
